## Project Phases

### Phase 0 — Learn Just Enough Java

Build enough Java fundamentals to comfortably work on the project, including classes, objects, methods, collections, and basic OOP.

### Phase 1 — Build the Skeleton

Establish the project structure, packages, classes, configuration, menu system, and basic application flow.

### Phase 2 — Scan the File System

Build the first real feature: recursively scan directories, discover files and folders, and generate scan summaries.

### Phase 3 — Represent Files as Objects

Create structured objects to represent files and their metadata instead of working with raw paths and strings.

### Phase 4 — Build the Index

Create efficient data structures for organizing and retrieving file information without repeatedly scanning the entire file system.

### Phase 5 — Search

Implement file searching by filename, extension, and content.

### Phase 6 — Ranking

Rank search results based on relevance so that more useful matches appear first.

### Phase 7 — Configuration

Make Atlas configurable with options such as priority folders, ignored folders/extensions, and file-size limits.

### Phase 8 — Persistence

Persist the index so Atlas can start quickly without rebuilding the entire index on every launch.

### Phase 9 — Incremental Updates

Detect and process only files that are new, deleted, or modified instead of rebuilding the entire index.

### Phase 10 — Multithreading

Parallelize scanning and indexing to improve performance while introducing threads, executors, synchronization, concurrent collections, and thread safety.

### Phase 11 — Smarter Search

Improve search with partial matching, fuzzy matching, typo tolerance, and multiple keywords.

### Phase 12 — Better Search Experience

Add practical features such as search history, suggestions, filters, sorting, and the ability to open files and folders.

### Phase 13 — Performance

Profile and optimize Atlas by analyzing algorithms, memory usage, allocations, caching, CPU usage, and overall performance.

### Phase 14 — Polish

Finalize Atlas with logging, error handling, progress and performance statistics, tests, documentation, and architectural cleanup.
